# booking-core-msgbucket
 Booking Core: Ultimate Booking System
 
 Installation:
 
 - Download the "booking-core-msgbucket-v3.6.1.zip" file from the downloads tab
 - Unzip the downloaded .zip file to the root of your website
 - Log in to your Booking Core admin panel.
 - Go to Tools, then Clear Cache.

Settings:

 - Select the Settings, then General Settings, then Sms settings.
 - Select SMS Driver "MsgBucket".
 - Enter your msgbucket Api Token .

Test Gateway Setting:

 - Select your country
 - Enter your WhatsApp Number
 - Enter your test message
 - Click Sms Test and you will see the test response like {Sms Test Success!}
